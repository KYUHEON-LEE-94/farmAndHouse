# 사계농가

현실 시간의 하루를 봄·여름·가을·겨울로 나누어 농사짓고 집을 꾸미는 힐링 웹게임입니다.

## 주요 기능

- 현실 시간 기반의 네 계절과 사용자 지정 운영 시간
- 계절별 현실 작물 12종, 성장 시간·난이도 기반 가격
- 심기, 성장, 수확, 판매로 이어지는 농사 루프
- 계절이 바뀌면 지난 계절 작물이 시드는 긴장감 있는 농사 규칙
- 계절별 물고기 12종과 0.1% 확률의 계절 전설 물고기 4종이 있는 강가 낚시터·도감
- 돌발 상황 → 선택지 → 버프/디버프로 이어지는 마을 이야기 텍스트 이벤트 12종
- 지붕·창문·원근 방을 갖춘 인형의 집 스타일 3단계 집, 가구 9종·벽 장식 3종 SVG 일러스트
- 벽지 4종·바닥재 3종 인테리어, 가구 색상 변경과 좌우 반전, 밤 조명 연출
- YouTube 링크를 이용한 농장 BGM
- 브라우저 자동 저장과 모바일 반응형 UI
- 웹과 Windows 위젯 각각의 자동 진행 저장
- 5분마다 기준가 ±10%로 바뀌는 농산물 시세
- 동전음과 금액 애니메이션이 포함된 수확·판매 효과
- 최대 16칸의 밭 확장 상점
- 드래그·터치·방향키 이동, 깊이에 따른 원근 크기, 반값 판매를 지원하는 자유 가구 배치
- 가구를 손실 없이 보관하고 다시 꺼낼 수 있는 영구 저장 창고

자세한 규칙과 밸런스는 [GAME_DESIGN.md](./GAME_DESIGN.md)를 참고하세요.

## 실행 방법

사계농가는 두 가지 방식으로 실행합니다.

### 1. 웹페이지

Vercel 프로덕션 주소 [farm-and-house.vercel.app](https://farm-and-house.vercel.app)를 브라우저에서 열어 바로 플레이합니다. GitHub `main` 브랜치가 연결되어 이후 변경 사항도 자동으로 배포됩니다.

로컬 웹 실행:

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

프로덕션 빌드:

```bash
npm run build
```

### 2. Windows 데스크톱 위젯

브라우저 없이 독립 창으로 실행할 수 있습니다. 기본적으로 다른 창보다 위에 표시되며 `Ctrl+Shift+T`로 항상 위 표시를 켜거나 끌 수 있습니다.

```bash
npm run desktop
```

배포 가능한 단일 실행 파일 생성:

```bash
npm run desktop:package
```

완성된 실행 파일은 `release/Sagyefarm-Widget-0.1.0.exe`에 생성됩니다. 게임 진행 상황은 위젯 전용 로컬 저장소에 자동 저장됩니다.

현재 데스크톱 위젯은 Windows x64만 지원합니다. 설치가 필요 없는 포터블 실행 파일이며, macOS와 Linux는 지원 대상이 아닙니다.
