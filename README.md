# 월루농가

**월급루팡 + 농가.** 근무 시간(기본 09:00~18:00)을 봄·여름·가을·겨울로 나누어, 일하는 틈틈이 농사짓고 낚시하고 3D 집을 꾸미는 힐링 게임입니다. (구 이름: 사계농가)

## 주요 기능

- 현실 시간 기반의 네 계절과 사용자 지정 운영 시간
- 계절별 현실 작물 12종(생육 20~58초, 손이 많이 가는 농사), 계절이 바뀌면 지난 계절 작물이 시드는 규칙
- 오른쪽 고정 도구함(단축키 1~6)으로 바꿔 드는 맨손·물뿌리개·우물·거름
- 물뿌리개로 직접 주는 물(우물에서 채우기)·거름(퇴비/고급/황금)·벌레 잡기로 결정되는 작물 품질(보통/좋음★/최상★★)과 벌레 피해(-10%/마리)
- 5분마다 기준가 ±10%로 바뀌는 농산물 시세, 최대 16칸의 밭 확장
- 계절별 9종·총 36종 물고기와 계절마다 0.1% 확률의 전설 물고기, 유료 미끼 4종, 물고기 도감
- 돌발 상황 → 선택지 → 버프/디버프로 이어지는 마을 이야기 텍스트 이벤트 12종
- PNG 업로드로 바꾸는 내 아바타(상단 프로필·낚시꾼·3D 집 캐릭터), 기본은 픽셀 고양이
- three.js **3D 집**: 360° 시점 회전, 벽 자동 컷어웨이, 가구 자유 각도 회전(5° 단위·Q/E 15°)
- 8평~45평 6단계 증축, 직사각형·정사각형·ㄱ자 구조 리모델링, **2층 증축**, 가벽·아치 가벽·문·창문·계단
- **마당 꾸미기**: 3단계 마당 넓히기, 울타리·꽃밭·연못·사과나무·가로등·강아지 집 등 마당 소품 10종
- 냉장고·주방·욕조·벽난로·월루 업무 책상 등 가구 20종과 벽 장식 7종
- 1회 1,000원 펫 뽑기: 능력 펫 7종(10%, 각자 고유 버프)·일반 펫 8종(90%), 되팔기 50%, 집 안을 돌아다니는 펫
- 가구·벽 장식 색상 변경, 벽지 4종·바닥재 3종, 낮/밤 조명, 창고 보관과 반값 판매
- YouTube 링크를 이용한 농장 BGM
- 웹과 Windows 위젯 각각의 자동 진행 저장, 모바일 반응형 UI

자세한 규칙과 밸런스는 [GAME_DESIGN.md](./GAME_DESIGN.md)를 참고하세요.

## 실행 방법

월루농가는 두 가지 방식으로 실행합니다.

### 1. 웹페이지

Vercel 프로덕션 주소 [farm-and-house.vercel.app](https://farm-and-house.vercel.app)를 브라우저에서 열어 바로 플레이합니다. GitHub `main` 브랜치가 연결되어 이후 변경 사항도 자동으로 배포됩니다.

로컬 웹 실행:

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

프로덕션 빌드:

```bash
npm run build
```

### 2. Windows 데스크톱 위젯

브라우저 없이 독립 창으로 실행할 수 있습니다. 기본적으로 다른 창보다 위에 표시되며 `Ctrl+Shift+T`로 항상 위 표시를 켜거나 끌 수 있습니다.

```bash
npm run desktop
```

배포 가능한 단일 실행 파일 생성:

```bash
npm run desktop:package
```

완성된 실행 파일은 `release/Wolru-Farm-Widget-0.1.0.exe`에 생성됩니다. 게임 진행 상황은 위젯 전용 로컬 저장소에 자동 저장됩니다.

현재 데스크톱 위젯은 Windows x64만 지원합니다. 설치가 필요 없는 포터블 실행 파일이며, macOS와 Linux는 지원 대상이 아닙니다.
