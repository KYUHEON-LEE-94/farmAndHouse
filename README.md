# 월루농가

**월급루팡 + 농가.** 근무 시간(기본 09:00~18:00)을 봄·여름·가을·겨울로 나누어, 일하는 틈틈이 농사짓고 낚시하고 3D 집을 꾸미는 힐링 게임입니다. (구 이름: 사계농가)

## 주요 기능

- 현실 시간 기반의 네 계절과 사용자 지정 운영 시간
- 계절별 현실 작물 25종(생육 20~58초, 손이 많이 가는 농사), 계절이 바뀌면 지난 계절 작물이 시드는 규칙
- 오른쪽 고정 도구함(단축키 1~7)으로 바꿔 드는 심기·수확·물뿌리개·우물·거름, 심기와 수확 분리
- 4단계 심기 도구(손 심기·모종삽·씨앗 파종기·꼬마 트랙터, 최대 4×2칸 한 번에 심기), 어떤 도구로든 벌레 잡기
- 4단계 물뿌리개(용량 5~18, 한 번에 1·2·4·4×2칸)와 4단계 수확 도구(맨손·호미·낫·황금 갈퀴)로 범위 물주기·범위 수확(우물에서 채우기)·거름(퇴비/고급/황금)·벌레 잡기로 결정되는 작물 품질(보통/좋음★/최상★★)과 벌레 피해(-10%/마리)
- 🌦️ 실제 날씨 반영(Open-Meteo, 기본 서울·📍 내 위치): 맑음·흐림·안개·비·눈·천둥번개·폭염·한파별 성장/판매가/희귀 물고기/벌레 효과, 비 오면 자동 물주기, ✨ 황금 작물(판매가 ×3)
- 도구에 맞춰 바뀌는 마우스 커서(물뿌리개·거름·맨손·호미·낫·황금 갈퀴)
- 5분마다 기준가 ±10%로 바뀌는 농산물 시세, 최대 32칸의 밭 확장(칸이 많으면 6·8열 촘촘한 밭), 밭 요약 칩과 도구 안내 줄
- 낚시 장소 5곳(유료 입장권 10분 · 입장 확인 창, 장소별 배경), 낚싯대별 생김새
- 스타듀밸리식 낚시 미니게임(누르고 있기로 막대 조절, 퍼펙트 보너스, 보물상자), 5단계 낚싯대, 등급별 난이도
- 계절별 9종·총 36종 물고기와 계절마다 0.1% 확률의 전설 물고기, 유료 미끼 4종, 날씨·장소 조건의 ✨ 특별 물고기 8종, 📖 도감 탭(사계절 + 특별 물고기 도감)
- 돈을 다 잃어도 계속할 수 있는 파산 구제: 하루 한 번 너구리의 월루 지원금(300원), 미끼 없이 무료 낚시터에서 하는 🫳 맨손 낚시
- 뒷골목 도박장: 홀짝(×1.95), 슬롯머신(최대 ×300), 블랙잭(3:2) — 지면 거대한 너구리가 튀어나와 ㅋㅋㅋ 비와 "꽝!" 도장, 웃음소리로 약 올리는 딜러
- 돌발 상황 → 선택지 → 버프/디버프로 이어지는 마을 이야기 텍스트 이벤트 26종(회사 생활 이벤트 포함)
- 🙈 ESC 보스 키(사무직 엑셀 · 개발자 VS Code · 디자이너 Figma 위장 화면 선택), 설정한 퇴근 시간에 "월루~~" 퇴근 알림
- 기본 검은 고양이·픽셀 고양이 등 기본 캐릭터 14종 또는 PNG 업로드로 바꾸는 내 아바타(상단 프로필·낚시꾼·3D 집 캐릭터), 기본은 픽셀 고양이
- three.js **3D 집**: 360° 시점 회전, 벽 자동 컷어웨이, 가구 자유 각도 회전(마우스 휠·5° 단위 슬라이더·Q/E)
- 8평~45평 6단계 증축, 직사각형·정사각형·ㄱ자 구조 리모델링, **2층 증축**, 가벽·아치 가벽·문·창문·계단
- **마당 꾸미기**: 3단계 마당 넓히기, 울타리·꽃밭·연못·사과나무·가로등·강아지 집 등 마당 소품 10종
- 냉장고·주방·욕조·벽난로·월루 업무 책상 등 가구 20종과 벽 장식 7종
- 🐾 펫 키우기: 먹이·산책·교감으로 애정도를 채워 레벨업(최대 Lv3), 레벨마다 펫 능력 강화(×1 → ×1.25 → ×1.5)
- 🛍️ 상점: 가챠(아래)와 펫 먹이 4종(비쌀수록 애정도 많이)
- 🎁 상점 가챠: 펫 뽑기(전설 0.1% 사신수·구미호, 능력 10%, 일반) · 가챠 전용 가구 뽑기(황금 변기, 유니콘 흔들목마 등), 내 펫 넣기/빼기
- 가구·벽 장식 색상 변경, 벽지 4종·바닥재 3종, 낮/밤 조명, 창고 보관과 반값 판매
- YouTube 링크를 이용한 농장 BGM
- 처음 온 사람을 위한 📖 기능 소개 가이드(13단계, 화면 요소 강조, 건너뛰기·다시 보기)
- 🦝 너구리 캐릭터: 도박장·파산 구제 등 어디서나 약 올리는 츤데레 담당
- 👤 선택형 계정(개인정보 없이 아이디·비밀번호만): 진행 상황을 계정에 자동 저장하고 다른 기기에서 불러오기
- 웹과 Windows 위젯 각각의 자동 진행 저장, 모바일 반응형 UI

자세한 규칙과 밸런스는 [GAME_DESIGN.md](./GAME_DESIGN.md)를 참고하세요.

## 계정 저장소 설정 (Vercel)

계정 기능은 Upstash Redis를 쓴다. 한 번만 설정하면 된다.

1. Vercel 대시보드 → `farm-and-house` 프로젝트 → **Storage** → **Upstash (Redis)** 를 만들고 이 프로젝트에 연결한다(무료 요금제로 충분).
2. 연결하면 `KV_REST_API_URL`, `KV_REST_API_TOKEN` 환경변수가 자동으로 들어간다.
3. **Redeploy** 한 번. 그 전에는 계정 창에 "계정 저장소가 아직 연결되지 않았어요"가 뜬다.

## 실행 방법

월루농가는 두 가지 방식으로 실행합니다.

### 1. 웹페이지

Vercel 프로덕션 주소 [farm-and-house.vercel.app](https://farm-and-house.vercel.app)를 브라우저에서 열어 바로 플레이합니다. GitHub `main` 브랜치가 연결되어 이후 변경 사항도 자동으로 배포됩니다.

로컬 웹 실행:

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```

프로덕션 빌드:

```bash
npm run build
```

### 2. Windows 데스크톱 위젯

브라우저 없이 독립 창으로 실행할 수 있습니다. 기본적으로 다른 창보다 위에 표시되며 `Ctrl+Shift+T`로 항상 위 표시를 켜거나 끌 수 있습니다.

```bash
npm run desktop
```

배포 가능한 단일 실행 파일 생성:

```bash
npm run desktop:package
```

완성된 실행 파일은 `release/Wolru-Farm-Widget-0.1.0.exe`에 생성됩니다. 게임 진행 상황은 위젯 전용 로컬 저장소에 자동 저장됩니다.

현재 데스크톱 위젯은 Windows x64만 지원합니다. 설치가 필요 없는 포터블 실행 파일이며, macOS와 Linux는 지원 대상이 아닙니다.
